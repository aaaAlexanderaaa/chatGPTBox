# 网页中的功能：阅读、写作与复用

本轮依据 [10 月 21 日确认的产品方向](product/browser-assistant.md)实现。

页面功能沿用既有链路；[10 月 30 日首批增强](product/browser-assistant.md#experience-design-2026-10-30)
已加入本地粘贴检查、ChatGPT 草稿入口和独立设置。两项默认关闭。
[交付记录](plans/2026-10-30-chatgpt-native-input.md)区分已通过的合成浏览器检查、
尚待完成的真实官网兼容性与安装状态；源码和构建不代表已替换你安装的扩展。

在网页上右键选择 `ChatGPTBox → 功能…`，或选择文字后点击划词栏中的
魔棒图标。内置和自定义的做法统一称为“功能”，在 `完整设置 → 功能` 中一起管理。
右键菜单、划词栏和功能选择窗口读取同一个目录，各自只是调用入口；新增入口
不需要再创建一种功能。每项功能可以独立选择显示入口。

功能目录保留原有翻译、总结、润色等做法，并提供正文速览、链接速览、导读与标注、
改写输入。可以直接修改处理要求、选择 AI 连接，或将好用的做法保存下来。
旧自定义工具的名称、提示词模板和启停状态会保留；修改时转换成同一种功能记录。

运行前，“交给 AI 的材料”明确区分四种范围：

- **仅发送链接**：保留当前链接的查询参数和片段，不附加正文。是否能访问
  链接取决于所选 AI；预置要求无法访问时如实说明。
- **选中的文字**：只使用打开助手时选中的文字，没有选文时不回退到正文。
- **当前正文**：读取当前页面的 article/main 区域，无此区域时读取可见正文；
  排除导航、隐藏元素、输入框和扩展自身界面。最多提供 30000 个字符，截取
  时有明确提示，实际范围可在“预览发送内容”中查看。
- **输入框文字**：有选文时处理选中的部分，否则处理整个输入框。密码和只读
  输入不提供改写入口。长输入会要求缩小范围，不静默截断。

点击“运行”才调用 AI。连接选择顺序为本次指定、功能指定、网站设置、全局
设置；保存的连接不可用时提示调整，不自动换连接。关闭助手或调整要求会断开
本次扩展请求。此轮没有持续任务或跨页面恢复能力。

## 在当前工作中使用结果

普通回答沿用已有聊天窗口，可以继续追问；需要调整连接或材料时点击“调整要求”。

**导读与标注**要求模型返回导读和逐字引文。扩展核对原文块、引文及唯一性，
仅允许核对通过的标注定位到页面。点击“在原文中标注”添加浏览器原生高亮；
“查看原文”选择并滚动到原文。正文发生变化会拒绝定位。无法解析的结果保留
原始回答，并说明原因。高亮可清除，关闭助手时也会清除。

**改写输入**先并列显示原文和建议。点击“应用改写”才替换，且只修改当时
选中的部分；支持 textarea、文本 input 和 contenteditable。网页已导航、
输入已改动、编辑器拒绝写入时不会覆盖原文。支持一次撤销；应用后的输入又被
改动时，拒绝用撤销覆盖新内容。复杂编辑器若不接受原生输入事件，可以复制结果。

## ChatGPT 官网输入增强

在完整设置的 `Sites`（网站）中找到“ChatGPT 官网增强”，可分别开启
“改写草稿”和“本地粘贴检查”，无需开启 ChatGPT Web 引擎或本机 gateway。
开启粘贴检查后，以及安装或更新扩展后，请刷新 ChatGPT 页面；已有旧页面不能获得新版本的早期拦截。

“改写草稿”在 `https://chatgpt.com/` 或 `/c/...` 的主输入框旁出现。
有选文时使用选文，否则使用输入框文字。点击后先预览材料、要求和连接，
点击“开始处理”才调用已有连接。随后比较原文与建议，选择应用或撤销。
不会自动向官网提交聊天消息。没有可用连接时先按提示配置连接。

“本地粘贴检查”仅在桌面 Chromium 构建提供。关闭时不装载早期粘贴脚本；
开启时先核对注册结果再保存开关，关闭时先核对移除结果。失败时会明确提示
“状态未确认，请勿依赖其保护”，需重新加载扩展后重试。已确认关闭的页面在
规则、语言等配置刷新时继续原生粘贴。已开启页面的配置暂不可读时，
主输入框会要求稍后重试。其他搜索、重命名等输入框保留官网原行为。
返回缓存页面后会重新读取设置，不恢复旧的待确认粘贴；输入法组合期间暂停
粘贴和改写，需先结束组合输入。
普通 `Ctrl/Cmd+V` 的纯文本
在本机按规则检查：完整且未命中时插入；命中时自动打开扩展源的“粘贴审查”，
并列显示原文与将插入的文本。勾选需要替换的命中项，点击“插入所选结果”
才写回原位置；已知密钥项不能取消遮盖。也可以取消，或展开“仅此次插入
原文纯文本”并明确确认。富文本需先确认转成纯文本，不静默丢掉格式。
有命中但所选结果完全等于原文时（例如取消所有非密钥项、使用 `$&`），
还须勾选确认将原文交给网站，才能插入所选结果。
等待期间再次粘贴会提示先完成或取消；继续编辑、切换目标、关闭窗口或导航
会使该操作失效。失败不自动贴入原文，确认窗口最多保留五分钟。

支持的规则为 ASCII 邮箱、中国大陆手机号格式候选、`sk-`/GitHub 令牌/Bearer
格式，以及“正则替换规则”中的自定义条目。点击“添加规则”，填写“匹配表达式”、
“匹配标志”和“替换文本”，再“保存规则”。表达式使用 RE2 语法，不加 `/.../`；
标志支持 `i`（忽略大小写）、`m`（多行）、`s`（点号跨行），始终全局匹配，`g` 可省略。
不支持环视和表达式内反向引用；`\w`、`\b` 使用 RE2 的 ASCII 词字符边界，中文应直接写字符或字符类。

例如表达式 `示例[甲乙]公司`、替换 `[客户]` 会处理两个公司名变体；
`编号[:：]\s*([0-9]+)`、替换 `编号[隐藏]` 会处理不同冒号和空白。
替换文本留空表示删除；`$$` 是字面美元符号，`$&` 是本次完整命中，
`$1` 或 `$<name>` 引用已声明捕获组。未参与本次匹配的可选组替换为空。
不接受 `$0`、`$01`、`$100`、未知捕获组、其他未约定美元语法或全文前后缀引用。
捕获组可能保留敏感片段，请查看审查窗中每项的“原文 → 替换”和完整候选。

每条从左到右进行不重叠匹配：`aba` 在 `ababa` 中只命中前一处，
不会枚举所有重叠出现。不同规则只扫描原文，不连锁处理前一条的替换结果。
跨规则重叠合成一项；一条自定义命中完整覆盖内置邮箱/手机号时采用其替换，
多个自定义命中冲突或仅部分交叠时整段使用 CUSTOM 遮盖别名，并显示冲突。
任何已知密钥命中都会锁定整个重叠范围；最终所选结果若因替换或拼接形成已知密钥，
会阻止确认插入，需调整规则或勾选项。明确确认的“仅此次插入原文”仍是独立选择。

最多 100 条，每条表达式最多 512、替换模板最多 256 个 UTF-16 单位，
每条最多 16 个捕获组；单条编译指令最多 512、合计 16384。单次输入最多 20000、
合并前命中最多 200、单项展开替换最多 20000、任意勾选组合输出最多 40000 个单位。
编译/匹配步骤之间检查 500ms 软预算，不能中断单次引擎调用，也不保证硬延迟上限。
无效规则、零长度命中和超限均按检查未完成处理，不自动插入原文。

旧敏感词会转义为字面表达式，默认替换 `[REDACTED]`；保存后使用条目格式，
不再为这些自定义词生成身份别名。规则保存在本机配置中，也会进入完整配置备份；
粘贴原文和临时占位符不保存到配置、聊天历史、日志或导出。内置规则和冲突使用的
别名在一次操作内保持稳定，不同操作分开；首批不提供回答还原。
无效导入不会被静默丢弃，设置会显示错误；修正后保存，或明确重置并保存。
写入失败时保留草稿并提示重试，不将草稿当成生效策略。另一设置窗口保存规则时，
本窗口未保存的内容会保留并显示冲突；先选“使用已保存规则”，或“保留我的草稿”
再保存（会覆盖当前已保存规则）。
读取设置时先显示加载状态；读取失败会要求重新加载设置，暂不提供官网增强的
修改控件。无效草稿与无效的已保存规则分开提示，不会把尚未保存的错误当成生效策略。

规则未命中不代表没有敏感信息，不能完整识别任意人名、地址或未知密钥。
检查只覆盖被拦截的粘贴事件：若网站另有剪贴板读取权限，仍可能独立读取
剪贴板。手工输入、已有草稿、脚本写入、附件/图片、拖拽和语音均未覆盖；
纯图片继续原路径并提示未检查，文件混合文本会拒绝本次插入。未识别的主编辑器显示不支持，不能视为受保护输入框。Firefox 不提供
自动粘贴检查；GPTs、登录页、代理页和其他 AI 官网也不在首批范围内。
当前官网的框架回填、账号切换和输入法组合仍以交付记录的实际验证为准。

## 保存、修改和分享做法

在助手中点击“保存为功能”，保存的是要求、材料范围、结果形式及可选连接，
不保存本次网页内容。保存后可从助手的功能列表再次使用。
追问中新增的要求会合并到待保存的处理要求中，保存前可以查看和修改。

`完整设置 → 功能` 支持新建、编辑、复制、启停、删除和 JSON
导入导出。导入同 ID 的功能会创建独立副本，不覆盖已有功能。预置始终可用，
修改后保存为自己的副本。已有划词工具及其配置继续保留。

当前可导入的格式示例：

```json
{
  "format": "chatgptbox.browser-functions",
  "version": 2,
  "functions": [
    {
      "id": "my-reading-guide",
      "name": "检查论证",
      "prompt": "标出论证最薄弱的原文，解释缺少了什么证据。",
      "scope": "page",
      "output": "annotations",
      "engine": "",
      "enabled": true
    }
  ]
}
```

`scope` 支持 `url`、`selection`、`page`、`input`；`output` 支持 `chat`、
`annotations`、`replacement`。标注需要正文或选文，改写需要输入框。
`engine` 为空表示跟随网站/全局设置，否则填写已有的 `provider/model`。
可选的 `entries` 数组指定入口，当前提供 `function-picker`、`context-menu`、
`selection-toolbar`，并保留未知入口供后续扩展。`template: true` 保留提示词模板语义，
`selectionOrPage: true` 允许无选文时使用正文。仍可导入已有的 version 1 文件。
导出只包含这些已知配置字段，不含提供商密钥和运行内容。

模型的前置思考与最终结果分开展示。导读支持 JSON 围栏及 JSON 前后的说明文字；
无法取得结构化导读时保留完整回答，不显示底层解析异常。改写应用与复制只使用
最终文字。仅有思考而没有最终答案时，会明确说明并保留思考内容。

内置名称和要求跟随当前界面语言，切换语言后会更新尚未修改的预置；用户自行
填写的名称和要求保持原文。“自动”语言读取已保存的用户语言，界面与回答语言一致。

这一格式服务于本轮真实功能。工程探索中的完整配方 schema、外部工具循环、
任务账本与翻译专项尚未实现，不能按当前格式直接导入执行。
