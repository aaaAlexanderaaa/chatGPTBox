# ChatGPTBox 产品定义

ChatGPTBox 让用户在浏览、阅读和写作的地方，用自己选择的 AI 处理眼前的
工作，并把好用的做法留下来继续修改和复用。

## 当前方向与维护位置

[浏览器助手的产品承诺与心智模型](browser-assistant.md)记录了 2026-10-21
已确认的方向：主入口在用户当前工作的网页，配置库服务于管理与扩展；用户
不需要先学会组装助手。它拥有这一方向的详细约定，本文负责产品总入口。

[产品契约](contracts.md)拥有跨功能的行为、失败和能力边界。
[浏览器助手使用说明](../browser-assistant.md)解释已经交付的页面功能及格式。
[架构](../../ARCHITECTURE.md)解释代码与运行边界。上述文档各有职责，不能
把工程候选、使用示例或旧执行顺序当作产品定稿。

## 用户与使用结果

用户可以直接提问，也可以使用或修改预置功能。阅读需要解答、依据与原文定位；
写作需要比较并采用修改；委派操作需要明确的进度、控制和结果。结果形式由
当前工作决定，不要求全部装进同一种聊天卡片。

用户选择 AI 连接、指定交出的材料，并能理解当前能力和限制。链接、选文、
正文和输入框文字各有明确语义。保存的是可复用的做法，不是未经说明收集的
网页内容。高级组合不能增加普通使用的前置负担。

## 引擎与扩展的分工

项目继续支持用户配置的 API、网页会话引擎以及外部 DeepSeek Harness。
API、网页连接或 agent 的名称不能替代实际能力判断；L1/L2/L3 只保留为
旧设计与内部讨论的背景，不要求用户先选能力等级。具体承诺见
[所选能力与材料范围](contracts.md#所选能力与材料范围)。

扩展承担浏览器上下文、连接、结果交互和做法复用。模型与外部引擎承担其真实
具备的理解、规划和执行能力。原文标注和用户确认的输入改写属于扩展的页面
交互；DeepSeek Harness 的工具执行仍归本机 harness。旧文档中“扩展不执行
任何工具”的说法不能禁止已确认的页面交互，也不能被解释为允许在扩展内新增
通用 agent 运行时。

## 范围与尚待验证的目标

完整配置与开放接入的空间保留；通用配置编辑器、工作流画布、长期记忆和统一
编排平台不因未来可能需要就成为前置建设。翻译专项暂缓，已有翻译提示词继续
沿用通用功能机制。后续参考与重新评估条件由
[浏览器助手方向](browser-assistant.md#翻译范围与后续参考)维护。

Grok Web 和 DeepSeek Harness 的专项设计分别见
[Grok 目标](2026-08-17-grok-web-design.md)与
[完整客户端目标](2026-08-18-dsh-full-client-design.md)。代码存在不代表真实
账号兼容、页面级对等或人工终验已经完成。旧版首答 60 秒、审批 3 秒/2 次
操作、设置可寻性等目标保留在[原始产品定义](../history/2026-08-15-product-definition.md)
和[原始验收清单](roadmap.md)中；本文不把它们改写为本轮已经测得的结果。
