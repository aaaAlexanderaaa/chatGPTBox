# ChatGPTBox 产品定义

> 状态：**生效中**（后续 UI/UX 与实现决策须能对回本文某一条）
> 日期：2026-08-15
> 来源：产品定义讨论定稿

## 一句话承诺

> **任何引擎，任何页面，按你的方式。**

ChatGPTBox 是浏览器与 AI 之间的**匹配层**。每一次 AI 使用由三件事配对而成：
**场面**（你此刻在哪、正看什么）× **引擎**（谁来回答）× **指令**（按什么规矩回答）。
产品的职责是把三个轴解耦、让用户自由配对、并在每个浏览瞬间给出合理的默认配对。

我们不是模型、不是聊天平台、不是 agent 运行时。我们是集成层。

差异化立场：竞品 sidebar 绑定自家模型与付费墙；我们把"你已有的网页会话"
（ChatGPT Web，零成本零配置）与"完全跑在本机的引擎"（Ollama、DeepSeek Harness）
纳入同一个表面。开源、无账号、引擎自由。

## 用户与任务

| 用户 | 任务 | 产品对他们的意义 |
| --- | --- | --- |
| 浏览中的人（存量主体） | 即时理解与产出：问、译、总结、改写 | AI 发生在我已经在的地方 |
| agent 操作者 | 不被本地 agent 卡住、顺手喂料 | DeepSeek Harness + 审批找得到人 |
| 前两者的交集 | 正在读 x、想让 agent 去做 y | **浏览器成为 agent 的眼睛**——融合才成立的能力 |

大部分用户大部分时间只在调一个 API。agent 是能力谱系的顶端，不是产品的主角。

## 三个用户概念（用户心智中的产品结构）

设置的组织就是这三个词，代码结构必须服从它们，而不是反过来：

1. **引擎（找谁）**：所有引擎一张统一解剖图——名称、连接状态、能力徽章、
   凭据或端点、诊断、设为默认。不存在"每家配置长得不一样"。
2. **集成（在哪）**：浮窗、划词气泡、搜索侧栏、popup 各自可开关、可绑引擎。
   站点兼容在产品语言里是**地点规矩**："在这个网站上这么表现"。
3. **指令（做什么）**：系统提示词是全局语气；自定义工具是可携带的指令；
   搜索查询是指令的一种触发方式。指令 × 引擎 × 触发场景组合出工具箱。

外观与数据是两个附庸概念，不与上面三个交叉。

## 引擎能力谱系与表面自适应

引擎不是平行列表，是三个能力层级；**表面随引擎能力自适应**：

| 层级 | 例 | 特征 | 表面形态 |
| --- | --- | --- | --- |
| L1 问答 | 各家 API | 无状态，问一次答一次 | 纯净的聊天窗 |
| L2 会话 | ChatGPT Web、Moonshot Web | 服务端记忆，历史可同步 | 聊天窗 + 会话连续性 |
| L3 代理 | DeepSeek Harness | 有工具、有过程、长任务、需授权 | 聊天窗长出时间线与审批卡 |

两条锁定原则：

- **L3 引擎不被"调用"，而被"参与"**：接了 agent 引擎，浮窗长审批卡、
  sidepanel/全页长出 DeepSeek Harness 全页客户端——这是引擎能力决定的表面形态，不是可选功能。
- **自适应是双向的克制**：对 L1 引擎，浮窗保持纯聊天窗的干净，不提前长器官。

## 三层承诺

- **首启**：60 秒内得到第一个答案。没有任何 API key 时产品也必须能用。
- **日常**：90% 的使用不打开设置、不切换标签页。打扰为零。
- **进阶**：每一层都可换——站点级换引擎、工具级换指令、任务级换到 agent。
  力量密度渐进披露：默认界面安静，深度按需展开。

设置结构的对应承诺：**结构跟着心智走**（找谁/在哪/做什么/长什么样/我的数据）。
检验标准：让一个没见过的人找一个指定设置项，试错不超过一次。

## 成功标准

- 新用户从安装到第一个答案 ≤ 60 秒。
- 从任意浏览器状态到应答一次 agent 审批 ≤ 3 秒、≤ 2 次操作。
- 来自页面上下文的 prompt 占比（量"浏览器成为 agent 的眼睛"是否发生）。
- 设置项可寻性：定位任一设置的试错次数 ≤ 1。

## 明确不承诺什么

- 不替代本机 harness 进程——工具执行永远在引擎侧。扩展完整替代 DSH Web 客户端（设置、凭据、工作区、preset）。
- 扩展不执行任何工具——浏览器是眼睛和嘴，不是手。
- 暂不做多 agent harness 抽象——模块缝留 capability 声明，不为假想的第二个引擎建层。
- 不做数据搬运工——会话状态归引擎侧，扩展不复制第二份真相。
- 不做打扰式完成通知——默认只有"需要你"的事件才说话。
