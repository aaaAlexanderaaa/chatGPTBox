## 设计前提

DeepSeek Harness 不是普通聊天软件。聊天软件的问题空间是对话；DeepSeek Harness
的问题是**监督一个替你干活的东西**——看它干到哪了、回答它的提问、必要时踩刹车。
组织原则：

> **叙述是主角，行动可检视，决策最响亮。**

中栏是 DSH Web 对话流——用户气泡、可检视工具行、响亮的审批/提问卡（见 D-23）。
浮窗与 popup 仍保留 L1/L2 引擎下的表面自适应（见 definition.md）。

## 全页布局（~1200px+）

```
┌─────────────────────────────────────────────────────────────┐
│ DeepSeek Harness  ● 本机 · 版本    设置    [N 个在等你]       │
├──────────┬──────────────────────────────────────────────────┤
│ 工作区   │ 会话标题   模式  模型  权限  自动审批  jobs skills │
│ + 添加   │ [对话] [轨迹]                                     │
│ 搜索     ├──────────────────────────────────────────────────┤
│ ▸ 仓库A  │ 对话流                                            │
│   会话   │                                                  │
│ ▸ 仓库B  ├──────────────────────────────────────────────────┤
│          │ 排队 · todo · 目标 · 上下文          [标准模式 ▾] │
│          │ +  /plan  权限  模型     输入              发送/停│
└──────────┴──────────────────────────────────────────────────┘
```

- **全局头**：DeepSeek Harness 身份 + 本机端点 + 版本 + 健康点（诊断结果即此点，点击展开）。
  设置从全局头进入同一面板。等待药丸 `[N 个在等你]` 仅在跨会话有待决策时出现。
- **侧栏**：工作区分组 + 会话列表，host 流实时驱动。`origin: 'subagent'` 的会话不出现在侧栏。
  状态色：● 蓝 运行中 / ◐ 琥珀 等你 / ○ 灰 闲置。搜索支持标题过滤 + 全文
  （`session.search`，结果内联带片段）。
- **会话栏**：标题（可改）、模式下拉（Agent Preset）、模型芯片、权限芯片、
  **自动审批开关**（D-8：手边、显式、默认关）、jobs/skills 入口、
  view tabs（对话 / 轨迹）。
- **对话流**：用户气泡 + 可检视工具行 + 审批/提问卡（对齐 DSH Web，见 D-23）。
- **Composer**：排队 · todo · 目标 · 上下文占用；`+` 命令菜单、`/plan`、权限、模型；
  输入区 + 发送/停止。

## 对话流：三语域

**散文语域**（默认阅读对象，视觉主导）：assistant 文本全宽可读排印
（15px / 行高 1.7 / ~68ch），markdown 完整渲染，todo 渲染为紧凑清单块。

**机器语域**（可检视，收敛）：工具活动一行一条——

```
🔧 shell  rm -rf node_modules && npm install   ◌ 12s
🔧 edit_file  src/config/storage.mjs           ✓
```

等宽字；参数预览 ~60ch 截断；状态符 ◌ 运行（脉动）/ ✓ / ✗ 红 / ⊘ 取消；
用时实时走秒。**运行中的行即契约要求的状态行**（静默期上限由此兑现）。
点击展开双栏：完整参数 + 结果（mono 块，错误标红）。默认不展开、不换行。

**决策语域**（最响亮，唯一允许通栏着色）：审批卡与提问卡，见下。

**Turn 边界**：细分隔线 + 结尾注记——`完成 · 3 步 · 2 工具 · 14s`；
特殊如实：`到达输出上限` / `被拦截` / `已停止` / 红色 `出错 · 原因`
（契约：turn 怎么结束永远有交代）。step 层级骨架 v1 不渲染。

## 决策卡（钱组件）

```
┌────────────────────────────────────────────────┐
│ ⚠ 等你决策 · step 4 · shell                     │
│   rm -rf node_modules && npm install           │
│   （完整参数 · mono · 可滚动 · 不折叠）           │
│ 前文: "依赖损坏，需要重装才能继续…" ▸            │
│ [ 允许一次 (a) ]  [ 拒绝 (r) ]   本次会话自动 ▸   │
└────────────────────────────────────────────────┘
```

- **完整参数永远直出**（可滚动，不藏在"展开"后）——契约"透明先于行动"；
  D-7 同等醒目：每张卡同样满、同样响，不做风险分级。
- 键盘 `a` / `r` 直达；新卡到达且焦点在对话流内时，焦点环自动落卡。
- "本次会话自动"是卡上第三动作，与会话栏开关同源同状态。
- 提问卡同骨架：选项列表（勾选）+ 自由文本 + 提交（`question/requested` 结构）。
- 决策完成后塌缩为一行安静记录（`✓ 已允许 · shell · step 4`）。
- **收件箱即导航**：侧栏 ◐ 行与全局头药丸都跳转到那张卡（自动滚动展开），
  一张卡只有一个实例一个身体，杜绝状态漂移。

## Composer

- 多行自动增高；`/` 唤起命令浮层（`skill.list`）；粘贴 / 拖入即附图
  （协议图片块）。
- queue / steer 分段控件只在 turn 运行时露出（steer 平时不存在）。
- 页面派活的上下文以**芯片**呈现于输入区上方（`[📄 选区 320 字 ×]`）——
  契约"上下文即所见"。
- 运行中：发送钮变"排队"，旁出 `[■ 停止]`（契约：停止即停止、永远够得着）。
- 排队指示 `⧗ 已排队 1 条`，可撤回（`updateQueue` remove；编辑 v1.5）。
- 流式 autoscroll 仅在用户已在底部时跟随；滚离出"回到最新 ↓"药丸，
  不劫持滚动。

## 三档（一套响应式组件）

| 档 | 宽 | 形态 |
| --- | --- | --- |
| 全页 | 1200+ | 上图完整布局 |
| Sidepanel | ~400 | 侧栏折叠为会话栏下拉；对话流全宽；其余同 |
| Popup | ~355 | **等待卡钉顶（第一职责：解堵 ≤2 操作）** + 会话尾部 + composer |

Popup 保留 composer（D-19）：quick ask 在浮窗不可用/不合适的页面（被排除
站点、新标签页）落在 popup。硬要求：**popup 与 sidepanel 草稿自动保存，
任何失焦不丢字**。

## 视觉语言

- **长在 ChatGPTBox 里**：复用现有 token（background / card / secondary /
  foreground / muted-foreground / border），暗色模式天生对齐，不另起体系。
- 两副字面：UI 与散文 = 系统 sans（15px）；机器语域 = ui-monospace（13px）。
- 色彩语义五枚封顶：琥珀 = 等你、蓝 = 运行中、绿 = 完成（淡出）、红 = 错误、
  灰 = 其余。
- "等你"一色制，但落 **两个 token**（D-17）：`--dsh-waiting-approval` 与
  `--dsh-waiting-question`，v1 同值（琥珀），允许日后分色。

## 键盘（v1）

`j/k` 会话移动 · `Enter` 打开 · `a`/`r` 决策 · `Tab` 等待卡轮转 ·
`/` 搜索 · `Esc` 收起 · `⌘↩` 发送。`⌘K` 命令面板为 fast-follow。

## 状态设计

- 无会话：居中一行 + "新建会话" + 浮窗路径提示。
- 会话空白：composer 聚焦，占位符给出示例与 `/` 提示。
- 引擎不可达：整面诚实错误态（端点 + 诊断按钮）；会话列表来自引擎侧，
  离线即不可示，不展示假列表。

## 契约对照

| 界面元素 | 兑现的契约 |
| --- | --- |
| 运行中工具行 + 走秒 | 静默期不超过一条状态行 |
| 决策卡（钉顶、通知、双 token 琥珀） | 审批生命级：绝不错过、≤2 操作 |
| 完整参数直出 + 卡上自动审批开关 | 透明先于行动；D-7/D-8 |
| 停止按钮常驻 composer | 停止即停止 |
| 上下文芯片 | 上下文即所见 |
| Turn 结尾注记 | 结束方式永远有交代 |
| 全局头健康点 + 引擎名 | 引擎身份可见；失败可诊断 |
| autoscroll 跟随规则 | 永不无预告变形 |
| 草稿自动保存 | 五条永不（不无反馈地丢用户输入） |
