# 功能预期契约

> 状态：**生效中**（每个功能的 UI 与实现须兑现其契约；修改契约须先改本文）
> 日期：2026-08-15
> 来源：产品定义讨论定稿
> 上游：[definition.md](./definition.md)

一句话承诺是愿景；本文是每个功能的**预期契约**——用户在使用一个功能时
被允许建立的全部预期。契约的价值：让"预期以外的结果"在结构上不可能出现。

**失败本身不是违约；静默地错、无反馈地等、假装成功才是违约。**

## 承诺分级

承诺有成本，所以承诺分级。每个功能先被赋予等级，等级决定可靠性工程的投入：

| 等级 | 含义 | 典型功能 |
| --- | --- | --- |
| 环境级 | 可以不在场（缺席合法），但出现就必须完整正确 | 搜索侧栏 |
| 应答级 | 用户主动召唤，必须回应——答案或明确错误，不允许无反馈 | 浮窗、划词工具 |
| 交付级 | 必须交付，API 语义，中间细节全部由扩展吸收 | ChatGPT Web 桥、引擎调用 |
| 生命级 | 绝不允许错过（单向门：财产与安全） | L3 审批通知 |

## 契约四要素

每个功能的契约 = **触发**（何时何地成立）→ **结果**（形态、质量、时延）→
**失败**（用户看到什么、我们自动做什么）→ **边界**（什么明确不含，
且在事前或失败当下告知，绝不让用户撞上才知道）。

## 逐功能契约

### ChatGPT Web（交付级）

- 触发：任何表面发一条消息。
- 结果：消息送达**用户自己的**网页会话，结果被完整提取、流式返回。
  登录态检测、重连、风控规避、后台存活是扩展的责任——用户不需要知道
  这些存在，更不需要为它们的稳定性负责，得到的体验像 API 一样稳定。
- 失败：登录失效 → "登录态失效，一键去登录"；上游改版 → 如实报告
  "上游变更，等待适配"。**绝不把残缺内容当完整答案返回。**
- 边界：逆向走在灰色地带，可用性可能随上游变化中断；承诺的是
  "失败得快而诚实"，不是"永不失败"。内容质量归服务商。

### L1 API 引擎（交付级）

- 结果：请求 → 流式回答。配额、鉴权、网络错误以可行动的措辞浮现
  （"余额不足，去充值"，不是一串 HTTP 状态码）。
- 边界：交付归扩展，内容质量归引擎。key 只存本地，永不经手第三方。

### L3 agent 引擎（新领土，契约最重）

- 结果：prompt 发出 → turn 开始 → **全程可见**（时间线：第几步、什么工具、
  什么参数、什么结果）。任何静默期不超过一条明确的状态行
  （"正在执行 shell… 12s"），永不黑盒转圈。
- **审批（生命级）**：agent 需要用户时，用户一定会知道——badge + 系统通知；
  从通知、popup、浮窗、驾驶舱任何一处应答 ≤ 2 次操作；应答后 turn 继续，
  不需要人守着。反向承诺同样成立：**在用户显式打开该会话的 auto-approve
  之前，agent 一步都不会越过审批**，且该开关状态永远在视野内。
- 停止即停止：stop 真实传导到引擎侧；停不下来时如实说，不假装停了。
- 上下文即所见：发送前明示捕获了什么（"已附加选区 320 字"），
  绝不暗示看了整页而实际只有标题。
- 记忆即所属：会话记忆归引擎侧，关窗不丢，重开续上。
- 边界：工具执行发生在用户机器上、权限归 harness——扩展承诺**透明**
  （让你看见一切），不承诺沙箱（不替 harness 兜安全）。

### 浮窗 / 划词工具（应答级）

- 触发：按站点规矩出现；被排除的站点绝不出现；永不破坏页面布局、永不抢焦点。
- 结果：流式回答；**正在回答的引擎身份永远可见**；引擎为 L3 时长出审批卡。
- 失败：有界等待——超时前必有状态反馈，超时后是明确错误 + 一键重试/换引擎，
  永不无限转圈。
- 边界：页面抽取质量因站而异；抽取结果量化展示（"已捕获 1200 字"），
  抽得差时明说，不默默发空上下文。

### 搜索侧栏（环境级）

- 触发：已配置的搜索引擎结果页，页面加载完成后异步出现，
  **永不拖慢搜索页本身**。
- 失败：可以不出现（缺席合法，判例见文末）；一旦出现就必须是完整态——
  **宁可不来，不可来了是残的**。
- 边界：明确标注为扩展注入的内容，与搜索结果视觉可分。

### 会话与引擎切换（跨功能一致性）

- 同一会话在任何表面打开，看到同一内容。
- **换引擎时明示记忆语义**：L1 记在窗口内（扩展带历史重发）、L2/L3 记在
  服务端。切换瞬间一行提示"保留什么、丢失什么"（判例见文末）——
  用户绝不该在第三轮对话才发现引擎不记得前两轮。

## 反"预期以外"权利法案（五条永不）

1. **永不静默出错**——宁可响亮失败，不默默给错。
2. **永不无反馈等待**——每个等待都有状态和上限。
3. **永不假装记忆**——没看到的上下文不暗示看到。
4. **永不替用户做主**——审批、发送、切换永远是显式动作。
5. **永不无预告变形**——表面在不同页面行为一致，除非用户自己立过站点规矩。
