| Write a fixed report versus an interactive analysis | The former retains records/method/bases; the latter also verifies promised mark/control behavior. Neither creates widgets merely to satisfy a form |
| Checks pass but the requested result is still missing | Return to original scope and causal judgment; continue authorized work. Another checklist pass or a written next step cannot substitute |
