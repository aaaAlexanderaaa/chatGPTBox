# Verification evidence

Evidence records state what was inspected or run, the result, and its limits.
They support decisions without redefining them. Temporary captures and account
data stay in ignored local locations; commit only material appropriate for the
repository's audience.

- [2026-10-22 documentation reconciliation](2026-10-22-documentation-discipline.md)
  records the reference learning, repository findings, changes, and checks.

Existing dated implementation reports remain at their original linked paths;
they are not relabeled as fresh tests by this directory's existence.
