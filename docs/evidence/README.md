# Verification evidence

Evidence records state what was inspected or run, the result, and its limits.
They support decisions without redefining them. Temporary captures and account
data stay in ignored local locations; commit only material appropriate for the
repository's audience.

- [2026-11-07 project review](2026-11-07-project-review.md) follows product
  promises through workflows, material/result contracts and engine continuity,
  with independent observations, controlled component trials and the original
  implementation-defect witnesses. Subsequent repairs and their separate
  verification are tracked in the [core workflow delivery](../plans/2026-11-08-core-workflows.md);
  the original witnesses remain dated baseline evidence.
- [2026-10-22 documentation reconciliation](2026-10-22-documentation-discipline.md)
  records the reference learning, repository findings, changes, and checks.
- [2026-10-29 discipline refresh](2026-10-29-discipline-refresh.md)
  records the complete current source comparison, local rule changes,
  preserved boundaries, and verification limits.
- [2026-10-30 ChatGPT Web runtime](2026-10-30-chatgpt-web-runtime.md)
  records compatibility of the new public runtime, proxy-page refresh recovery,
  synthetic regressions, and the installed text-send/history-read observations.
- [2026-10-31 ChatGPT fetch diagnostics](2026-10-31-chatgpt-fetch-diagnostics.md)
  records the delegated native fetch and inline-export changes, their capability checks, and the
  installed gateway observations.
- [2026-11-04 history backup and functions](2026-11-04-history-backup-and-functions.md)
  records the retained-body and statistics defects, bounded file export,
  template-material repair, interaction checks, and synthetic resource probe.
- [2026-11-06 gateway process exits](2026-11-06-gateway-process-exits.md)
  records isolated input-triggered crashes, request containment, lifecycle
  diagnostics, the later runtime-discovery repair, live Get/MCP validation and
  the limits of the historical diagnosis.

- [2026-10-30 ChatGPT native input](2026-10-30-chatgpt-native-input.md)
  records local paste/rewrite and regex reviews, corrected defects, controlled
  browser and real guest-editor checks, and the October 31 installed v4.3.0 delivery.
  Logged-in rich-editor and transition acceptance remain open.

Existing dated implementation reports remain at their original linked paths;
they are not relabeled as fresh tests by this directory's existence.
