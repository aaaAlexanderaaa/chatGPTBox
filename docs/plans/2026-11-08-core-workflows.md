# 核心使用流程与已确认缺陷的收敛

本次本地交付已完成：实现、回归、四包构建、受控 Chromium 验证和最后代码差量的
独立评价均已闭合。下文保留各次未通过判断、修正、最终源码身份和验证界限；
这不代表真实账号、原生客户端验收或发布完成。

用户在分层 review 后询问必须做什么，随后要求“那么你继续”。本次交付是落实
[11 月 7 日 review](../evidence/2026-11-07-project-review.md)所定位的安全缺陷和
四个流程断点。实施前基线为 `7400b54`；review 文件和合成 witness 已在工作区。
本计划记录实施判断；永久行为分别回到产品、架构、网关、缓存和 Drafts 的 owner。

## 交付终点

1. 页面助手运行前冻结完整请求。模板需要的额外网页材料明确列出、可预览；
   不因 URL/选文范围偷偷扩展，也不在运行时重读 DOM。被预算截断的材料不能
   当作完整材料发送。保留高级模板用途，不以禁用整个模板机制替代修复。
2. 速览可以保留本次材料与附加要求，明确改为原文标注；改变结果使用方式后
   重新运行，保存的做法包含新的形式。复用读取新页面，不保存旧页面正文。
   正文抽取覆盖同一主要阅读区域的多个可见正文，避免 teaser article 排除 main。
3. 执行结束原因与最终正文分开。停止、断流、上游失败保留部分内容并说明状态，
   不进入正常改写采用/标注路径。DSH 工具进度仍可见，工具行/结束注记不进入
   最终改写文本。取消请求与“远端已停止”分别陈述；关闭 DSH 窗口仍是断开观察。
4. 换同一提供商的模型保留合法远端绑定；跨提供商保留本地可见记录，清除旧远端
   ID，明确开始新远端会话。网页引擎新会话只接收本次提问；API 重发本地历史。
   UI 先说明这个差异，不自动把整段历史打包发给另一个账号。切回旧引擎也按
   新远端会话处理。Grok 成功答复进入本地记录，导出与重新打开仍可见。
5. Drafts 的内容不被当作控制数据。生成一个文档级身份，所有动作控制块绑定
   该身份；只解析顶端有效身份与唯一匹配的控制块，重复或损坏时拒绝写入并
   保留全文。旧格式仅在可无歧义识别时迁移；不猜测、不释放不确定发送标识。
6. 网关幂等账本容量满时在新写入之前拒绝，不驱逐保护期内的旧标识；原有 key
   仍可读取/恢复。维持明确的七天有限保护期和私有原子落盘，不声称永久去重。
   ChatGPT 的实际发送前失败标为未发送；真正开始写入后的失败继续保护为不确定。
7. Functions 初读中/失败时 UI 和写入口均拒绝整表覆盖，保留草稿和可重试入口。
   ChatGPT 索引的新增、快照、同步写入走同一串行更新，避免并发漏项。
8. DSH 轻量入口明确选择工作区后才创建会话，已有绑定不另建；实时事件与历史按
   序号合并后折叠，历史较早帧不会被较新 live 帧丢弃。Ollama Stop 不触发额外生成。

## 实施前独立审查的首轮意见

三位只读审查者分别检查写边界、使用流程与 DSH/材料；共享同一原始证据和基线，
分别读取当前代码，不以角色名声称独立事实来源。首轮发现及处置：

- `design_write_boundaries`：Drafts 勾选列表、备用 Conversation ID、new-operation、
  photo 和 pending 标题也是控制面，须一起隔离；索引队列须放后台唯一 owner，
  不能只在跨上下文的模块中各建队列。均纳入实现。
- `design_workflow_boundaries`：高级模板的 autoRun 也须停下确认；空模板值不可回读；
  先前失败不能被 trailing done 覆盖。快照恢复会复活旧绑定，故加入持久绑定代次
  和对应 provider 的恢复门控，运行中禁切换。均纳入实现。
- `design_dsh_material`：历史前插会使 position baseline 失效，需一起改成稳定事件身份；
  审批/提问的无序号状态在重建时保留，不重复自动处理。纳入实现。

这些是设计审查意见，尚不是完成验证。最强较小替代为仅修十二个局部故障；
它不能闭合形式改变、材料共享和结果采用，故本次同时修正必要的生产/消费边界。

旧 Stop 确认会隐藏新的发送前拒绝；主代理说明再增加一次，仅检查这一状态差异。
不是重新计算既有次数或自动重试。目前本日实际提交六次，连同 11 月 8 日一次，
整个交付链共七次 `ask_chatgpt` 项目复核请求。没有发送真实运行测试消息或凭据。

初评交接包含原请求、实施边界、前五项发现、已观察验证及 22 个当前源码文件的

不以修正后的结果覆盖首轮判断。审查者只能静态读取交接文本，不能访问本机仓库
或独立重跑测试。初评报告的思考时长为 692 秒，不能等同于端到端耗时。

| 11 月 9 日首评意见 | 当前处置与证据 |
| --- | --- |
| Drafts 同一 key 在编辑后可能携带新请求，网关尚未记录旧请求时会真正发送新内容 | 新建与续聊始终恢复完整原请求，缺失原请求则拒绝；编辑保留为下一条未发文本。回归模拟网关未记录旧请求及已完成/仍不确定两类结果；旧测试中期望旧 key 携带新 query 的断言据不可变请求契约纠正 |
